🍽️ Zomato Data Analysis
📊 Project Overview
This project focuses on performing exploratory data analysis (EDA) on the Zomato Bangalore restaurant dataset. The aim is to extract meaningful insights about restaurant types, customer ratings, cuisine distribution, pricing trends, and location-based behavior. The dataset provides valuable information for food lovers, restaurateurs, and business analysts.

📁 Dataset
Source: Zomato Bangalore dataset (available on Kaggle)

Format: CSV

Size: ~10,000+ rows

Key Features:

Restaurant name, location, and type

Online order and table booking availability

Cuisines served

Average cost and price range

Ratings and votes

⚙️ Technologies Used
Python (Pandas, NumPy, Matplotlib, Seaborn)

Jupyter Notebook (for visualization and interactive analysis)

🔍 Key Questions Explored
Which restaurant types are most popular in Bangalore?

How does location affect restaurant rating and availability?

What cuisines are served most frequently?

Is there a correlation between average cost and rating?

How do price ranges vary across areas?

📈 Analysis Highlights
Data Cleaning:

Removed duplicates and nulls

Normalized column values (e.g., "Yes"/"No", "cost for two")

Data Visualization:

Heatmaps, bar charts, pie charts, distribution plots

Insights:

Online ordering is more common than table booking

North Indian and Chinese cuisines dominate the scene

Restaurants with high ratings cluster in specific areas like Indiranagar and Koramangala
